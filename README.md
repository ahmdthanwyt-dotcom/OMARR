# نظام إدارة المعاهد القرآنية المغلقة - إصدار Supabase 2026

منظومة سحابية متكاملة لإدارة المعاهد القرآنية، متابعة الحلقات، ورصد التسميع اليومي والتقارير الموحدة.

---

## 📁 محتويات المجلد:
1. **`index.html`**: واجهة النظام الكاملة (مجهزة للعمل مباشرة على متصفحات الويب و GitHub Pages دون أي خادم).
2. **`schema.sql`**: كود إنشاء وتهيئة قاعدة البيانات في Supabase وحل مشكلة المفاتيح الأجنبية `parent_username`.
3. **`README.md`**: تعليمات التشغيل والنشر.

---

## 🚀 طريقة التثبيت والرفع على GitHub:

### 1. إعداد قاعدة البيانات في Supabase:
1. ادخل إلى لوحة تحكم مشروعك في [Supabase](https://supabase.com).
2. من القائمة الجانبية، افتح **SQL Editor** (أيقونة `>_`).
3. اضغط على **New query**.
4. انسخ كامل محتوى ملف `schema.sql` والصقه هناك.
5. اضغط على زر **Run** الأخضر حتى تظهر رسالة `Success`.

### 2. رفع الموقع على GitHub Pages:
1. أنشئ مستودعاً جديداً (Repository) على حسابك في GitHub (مثلاً: `quran-system`).
2. ارفع ملفات هذا المجلد (خاصة ملف `index.html`).
3. اذهب إلى **Settings** داخل المستودع في GitHub.
4. من القائمة الجانبية اختر **Pages**.
5. تحت قسم **Build and deployment**، اضبط الفرع (Branch) على `main` ثم المجلد `/ (root)` واضغط **Save**.
6. بعد دقيقة واحدة، سيظهر لك رابط الموقع المباشر (مثل: `https://username.github.io/quran-system/`).
